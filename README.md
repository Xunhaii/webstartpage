# Xunhaii 起始页

> 简约优雅的浏览器起始页 · 自定义 · 响应式 · 无依赖

一个功能丰富、界面简洁的浏览器起始页。所有数据本地存储，无需登录、无需后端，开箱即用。

---

## ✨ 功能亮点

### 🔍 自定义搜索引擎
- 添加 / 编辑 / 删除任意数量的搜索引擎
- 自定义名称、搜索 URL 与图标
- 搜索 URL 使用 `{query}` 作为查询占位符
- 支持三种图标设置方式：**Font Awesome 类名** / **图片链接** / **上传本地图片**
- 鼠标悬停（触屏长按）引擎按钮时显示编辑入口
- 支持拖拽排序，自动保存顺序

### 📌 快捷方式管理
- 添加 / 编辑 / 删除网站快捷方式
- 每个快捷方式可设置独立图标（三种方式同上）
- **网格感知的拖拽排序**：支持跨行拖放，被挤开的卡片有流畅的 FLIP 动画
- 鼠标悬停 / 键盘聚焦 / 触屏轻触时显示编辑按钮
- 触屏两段式操作：**首次轻触**选中卡片 → 显示编辑按钮；**再次轻触**打开链接
- 支持删除时自动清理关联的 IndexedDB 图标数据

### 🕘 历史搜索
- 自动记录最近 **10 条**搜索记录
- 点击记录可一键重新搜索
- 单条删除 / 一键清空

### 🎨 主题系统
- 手动切换日 / 夜间模式
- 支持跟随系统主题（自动响应系统偏好变化）
- 浅蓝色主色调，柔和的渐变与毛玻璃效果

### 🖼️ 自定义背景
- 三种背景来源：**默认壁纸** / **图片链接** / **上传本地图片**
- 上传的图片存储于 **IndexedDB**，不受 localStorage 容量限制
- **四种视觉效果**实时调节：
  - 模糊（0 – 30px）
  - 亮度（50% – 150%）
  - 饱和度（0% – 200%）
  - 暗色遮罩（0% – 80%）
- **五种快速预设**：原图 / 梦幻 / 影院 / 黑白 / 鲜艳
- 独立预览区，所见即所得
- 背景效果与背景来源解耦，可自由组合

### 🧊 高斯模糊开关
- 一键开启 / 关闭页面所有毛玻璃效果
- 状态本地保存，刷新后保持

### 📦 配置导入 / 导出
- 一键导出全部配置为 JSON 文件（含 localStorage + IndexedDB 数据）
- 一键导入，快速迁移或备份
- 导入时校验文件来源，避免误操作

### 📱 响应式与交互
- 完整适配桌面 / 平板 / 手机
- 桌面端：鼠标悬停显示编辑按钮
- 触屏端：长按拖拽排序，轻触选中卡片显示编辑按钮
- 触摸 / 键盘 / 鼠标三端一致的交互体验
- 键盘无障碍支持（Tab 聚焦、Enter 打开、Esc 关闭模态框）

### 🚫 404 页面
- 与主页面共享设计语言、主题与背景设置
- 自动识别用户访问的路径并展示
- 一键返回首页 / 返回上一页

### 🔒 安全与性能
- 所有用户输入渲染前统一 HTML 转义，防止 XSS
- 背景层独立合成层，拖拽时不会引起背景抖动
- `<head>` 内联脚本首帧同步应用背景效果，避免刷新闪烁
- 图标与背景图片使用 IndexedDB 存储，突破 localStorage 容量限制

## 🚀 快速开始

### 方式一：直接使用
1. 下载 / 克隆本仓库
2. 将文件部署到任意静态服务器（Nginx / Apache / Vercel / Netlify / GitHub Pages 等）
3. 访问 `index.html` 即可

### 方式二：本地预览
由于涉及 IndexedDB 和字体资源跨域，建议使用本地服务器：

```bash
# Python 3
python -m http.server 8080

# 或 Node.js
npx serve
```

然后访问 http://localhost:8080。

🛠️ 技术说明

· 纯静态：无框架、无构建步骤、无外部依赖（仅使用 Font Awesome 图标库）
· 数据存储：
  · localStorage：搜索引擎配置、快捷方式列表、主题偏好、背景配置、搜索历史等
  · IndexedDB：上传的图标文件、上传的背景图片
· 浏览器兼容：现代浏览器（Chrome / Edge / Firefox / Safari 的最新版本）
· 图标库：Font Awesome 7

---

🌐 服务器配置（404 页面）

· Nginx：error_page 404 /404.html;
· Apache：ErrorDocument 404 /404.html
· Vercel / Netlify / Cloudflare Pages：根目录 404.html 会被自动识别
· GitHub Pages：将 404.html 放在仓库根目录即可
